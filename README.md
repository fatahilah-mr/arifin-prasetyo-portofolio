This repository contains the source code for the premium culinary portfolio website of Arifin Prasetyo. It is built using a modern modular component-based architecture, prioritizing a **mobile-first** approach, and optimized for maximum performance and search engine indexing.

> [!TIP]
> The project utilizes modern tools like React 19, Vite, TanStack Router, and Tailwind CSS v4 for lightning-fast performance and an excellent developer experience.

## Features

- 🌐 **Floating Navigation Bar** - Modern navbar with backdrop blur effects and a responsive menu.
- 🍲 **Dynamic Culinary Gallery** - State-based filtering system for various dishes (Main Course, Pastry & Bakery, and Beverages).
- 📜 **Responsive Credentials Timeline** - Professional certification timeline with responsive image ratios.
- 🚀 **Production-Ready SEO Config** - Full support for Cloudflare Pages, Google Search Console, `robots.txt`, `sitemap.xml`, and `_redirects`.
- ⚡ **Modern Tech Stack** - Built for speed and flexibility with a highly optimized toolchain.

## Architecture

The project is structured following standard React and Vite conventions:

- `src/components/` - Modular UI components like `Navbar`, `Hero`, `Skills`, and `Gallery`.
- `src/routes/` - File-based routing handled by TanStack Router (e.g., `__root.tsx`, `index.tsx`).
- `src/main.tsx` - The main application entry point.
- `public/` - Static assets and SEO configurations (`robots.txt`, `sitemap.xml`, `_redirects`).

## Getting Started

To run this project locally, you need [Node.js](https://nodejs.org/) and the [Bun](https://bun.sh/) package manager installed on your machine.

**1. Clone the repository:**
```bash
git clone https://github.com/fatahilah-mr/arifin-prasetyo-portofolio.git
cd arifin-prasetyo-portofolio
```

**2. Install dependencies:**
```bash
bun install
```

**3. Start the development server:**
```bash
bun run dev
```

The site will be available at `http://localhost:5173`.

**4. Build for production:**
```bash
bun run build
```
The compiled static files will be generated in the `dist/` directory. You can preview it using `bun run preview`.
